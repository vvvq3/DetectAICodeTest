# rundetectai — запуск детектора ИИ-кода с публичной ссылкой

Скрипт сам:
1. останавливает прошлый запуск (порт 5057, туннель Cloudflare);
2. разворачивает проект в папку (если его нет) или делает `git pull`;
3. запускает веб-версию и туннель в фоне;
4. печатает ссылку и пароль.

Код MR никуда не отправляется — анализ локальный.

## Шаги

1. Выполни одной командой (Bash, таймаут 900000 мс: при первом запуске ставится .NET и собирается проект):

   ```bash
   bash ~/.claude/skills/rundetectai/rundetectai.sh $ARGUMENTS
   ```

   - **Если этого файла нет**, выполни:
     `curl -fsSL https://raw.githubusercontent.com/vvvq3/DetectAICodeTest/HEAD/scripts/rundetectai.sh | bash -s -- $ARGUMENTS`
   - **Куда ставится проект:** запускай в текущей папке сессии. Скрипт сам выбирает папку: та же, что в прошлый раз, или `./DetectAICodeTest`.
   - **Без аргументов:** адрес GitLab берётся из прошлого запуска.

2. **Код выхода 3** — адрес GitLab ещё не задан. Спроси у пользователя адрес (например `gitlab.company.com`) и повтори команду с ним.

3. **При успехе** ответь по-русски коротко и только это:
   - ссылка;
   - пароль (имя пользователя — любое);
   - с какого GitLab принимаются MR;
   - «остановить: rundetectai stop, перезапустить: rundetectai».

4. **При ошибке** покажи последние строки вывода и предложи решение:
   - нет интернета или VPN/файрвол блокирует Cloudflare — повторить без VPN;
   - нет git — `xcode-select --install`;
   - занят порт — скрипт освобождает его сам, повторить.

   Не выдумывай ссылку: показывай только то, что напечатал скрипт.
