## 1. Пользователь и правила работы

- **Язык общения — русский.** Пользователь (Иван) работает на Mac (MacBook Air), но инструкции нужны и для Windows (для коллег).
- **GitLab на собственном сервере пользователя**, токен он даёт сам (право `read_api`). Репозиторий с кодом — GitHub `vvvq3/DetectAICodeTest` (публичный). Ветка `claude/inspiring-lamport-i2ixa7` (ветка по умолчанию, коммитить и пушить в неё). Pull request без явной просьбы не создавать.
- **Жёсткое требование: код MR никуда не отправлять** — ни в Claude API, ни в другие внешние сервисы. Каждый признак реализуется локальным кодом. Тест «переписыванием через Claude» из исследования запрещён.
- **Задача:** MR либо целиком человеческий, либо написан Claude Code — третьего не дано. Ответ: вероятность в % плюс объяснение (какие паттерны ИИ найдены). Даты не использовать (нет «чистой» даты до ИИ). MR обычно ≥ 150 строк.
- **Как любит работать:** долго и автономно, по ходу коммитить, доводить до проверенного результата. Не тратить больше ~70% недельного лимита. При переполнении контекста — сжимать, но сохранять все его сообщения, исследование и план (этот файл).
- **Дальше:** такие же детекторы для других языков (см. раздел 10).
- **Удалённый доступ:** облачная сессия к Маку пока не подключается. Мак `MacBook-Air-Ann` виден с папкой `ClaudeWork`, но статус `not_available` (папка не отдаётся облачным сессиям). Чтобы запускать что-то на Маке и управлять с телефона, пользователь должен открыть сессию Claude Code на самом Маке: в Claude Desktop или `claude remote-control` в папке проекта.

## 3. Что построено (состояние)

- Репозиторий: https://github.com/vvvq3/DetectAICodeTest, ветка `claude/inspiring-lamport-i2ixa7`.
- **Стек:** .NET 10 (`RollForward=Major`), C#, Roslyn (`Microsoft.CodeAnalysis.CSharp` 5.9.0), DiffPlex 1.9.0, xUnit. Веб — ASP.NET Core minimal API (`CreateSlimBuilder`).
- **Запуск:**
  - Mac/Linux: `bash run.sh <ссылка>` (сам ставит .NET SDK 10 в `~/.dotnet` и собирает в `.build/`, пересобирает при изменении исходников).
  - Windows: `.\run.cmd <ссылка>` (вызывает `run.ps1` с `-ExecutionPolicy Bypass`; ставит .NET в `%LOCALAPPDATA%\Microsoft\dotnet`).
- **Режимы CLI** (`src/AiDetect.Cli/CliOptions.cs`):
  - анализ `<url>`;
  - `web` (`--port`, `--host`, `--password`, `--gitlab-host`, `--no-browser`);
  - `batch mrs.txt [--html dir]`;
  - `fetch <url> --save mr.json`;
  - `--load mr.json`;
  - `--git <repo> --base <ref> --head <ref> [--title]`;
  - `eval <corpus>`;
  - `calibrate <corpus> -o model/weights.json [--lambda 16] [--balanced]`.
  
  Общие флаги: `--token` / `GITLAB_TOKEN`, `--insecure`, `--api-url`, `--json`, `--html`, `--no-artifacts`, `--weights`, `-v`, `--no-color`.
- **Веб** (`WebServer.cs`):
  - одна страница; `POST /api/analyze` (form: `url`, `token`, `noArtifacts`) отдаёт HTML-фрагмент отчёта и заголовки `X-Probability`, `X-Verdict`, `X-Title`;
  - при `--password` — Basic auth, имя любое; `--gitlab-host` разрешает только MR с этого хоста (защита от SSRF);
  - слушает `127.0.0.1`, пока не задан `--host 0.0.0.0`.
- **`share.sh <gitlab-host> [пароль]`:**
  - скачивает `cloudflared` в `.build/tools`, генерирует пароль;
  - запускает веб без `GITLAB_TOKEN`, поднимает quick tunnel;
  - печатает ссылку только после строки `Registered tunnel connection`;
  - копирует сообщение в буфер, `caffeinate` не даёт Маку уснуть, Ctrl+C гасит всё.
  
  Проверен в контейнере до подключения к Cloudflare (DNS SRV в контейнере закрыт). На настоящем Маке ещё не запускался.
- Цвета в консоли Windows включаются через `SetConsoleMode` (`WindowsConsole.cs`).

## 4. Архитектура и алгоритм

```
Источник (GitLab API | локальный git | JSON) → MergeRequestData
  → Предобработка: FileClassifier (сгенерированное исключить, слой файла, тест или нет)
  → Для каждого изменённого .cs: Roslyn-разбор нового файла, область = добавленные строки (новый файл — весь)
      → CSharpFeatureExtractor → CodeStats (счётчики + примеры файл:строка); шаблонный код (DTO/Options/DI/Migration) с весом 0.5
  → Базовая линия проекта: старые версии изменённых файлов + до 14 соседних файлов каталогов на base → CodeStats
  → ProjectConventions из конфигов (StyleCop, GenerateDocumentationFile, .editorconfig, commitlint, шаблоны MR)
  → Сигналы: CodeSignals (код) + MrSignals (артефакты, форма MR, процесс) → SignalResult
  → Scorer: сумма вкладов по группе с ограничением → логит + смещение → p = sigmoid(logit / T)
  → AnalysisReport: вероятность, вердикт, надёжность, объяснение, топ-признаки, оценка по файлам, вклад групп
  → Console / HTML / JSON
```

Ключевые файлы:
- `src/AiDetect.Core/Model/MergeRequestData.cs` — модель данных: MR, коммиты, изменения с Old/NewContent, Notes, RepositoryContext (agent-файлы, BaselineFiles, ConfigFiles).
- `Sources/`:
  - `GitLabMergeRequestSource.cs` — API v4;
  - `LocalGitSource.cs`;
  - `JsonMergeRequestStore.cs`;
  - `TextDecoding.cs` — UTF-8 или cp1251.
- `Diff/UnifiedDiff.cs` (добавленные строки) и `Diff/LineDiff.cs` (дифф по двум версиям через DiffPlex).
- `Preprocessing/FileClassifier.cs` — сгенерированное, тесты, 16 слоёв.
- `Features/CSharpFeatureExtractor.cs` (Roslyn-обход) и `Features/CodeStats.cs` (ключи счётчиков `K.*`).
- `Signals/`:
  - `SignalBuilder.cs` — Map, Rel, Rate, AdjustForBaseline, ConventionFactor;
  - `CodeSignals.cs`, `MrSignals.cs`;
  - `SignalTypes.cs` — группы, ограничения групп, устойчивость к маскировке.
- `Analysis/`:
  - `MergeRequestAnalyzer.cs` — конвейер, базовая линия, объяснение, оценка по файлам;
  - `Scorer.cs`, `ModelParameters.cs` (веса, Bias, Temperature, `weights.json`), `ProjectConventions.cs`.
- `Evaluation/CorpusEvaluator.cs` (AUC, метрики, разделимость признаков) и `Evaluation/Calibrator.cs`.

**Модель признака:**
- Свидетельство `e ∈ [−1, 1]`. `Map(x, humanAt, aiAt)`: значение `humanAt` даёт −1, значение `aiAt` даёт +1.
- Надёжность `r = n/(n+k)`. Вклад в логит = `w·e·r`.
- Базовая линия: если код проекта уже обладает тем же свойством, `e` ослабляется на `alpha·e_base`, а пара (MR, проект) идёт в сигнал «сдвиг стиля» `shift.style`.
- Конвенции проекта умножают веса. XML-doc обязателен — `doc.*` ×0.2. StyleCop — порядок членов и явные модификаторы ×0.3. `.editorconfig` — синтаксис ×0.6. commitlint — стиль коммитов ×0.4.

**Скоринг:**
- Сумма вкладов по группе ограничена `GroupInfo.Cap`: артефакты 9, остальные 1.2–2.2.
- `p = sigmoid((Bias + Σ групп) / T)`, `T = 2.5`. После калибровки (`model/weights.json`, 77 весов): `Bias = −0.61`, λ=16.
- **Вердикты:** ≥85% — «почти наверняка Claude»; ≥65% — «скорее Claude»; 35–65% — «неопределённо»; ниже — «человек».
- Меньше 30 строк C# без артефактов — «недостаточно кода».

**Калибровка:**
- Логистическая регрессия по `x = e·r·conventionFactor` с L2-штрафом к экспертным весам; веса ≥ 0, артефакты не калибруются, Bias тоже штрафуется.
- По умолчанию без балансировки классов: смещение консервативное, меньше ложных обвинений, как требует исследование.
- Оценка — 5-кратной перекрёстной проверкой.

## 6. Источники данных — детали

**GitLab** (`GitLabMergeRequestSource`):
- Разбор ссылки `https://host[:port]/group/sub/project[/-]/merge_requests/N`.
- Запросы:
  - `GET /projects/:enc/merge_requests/:iid` (diff_refs);
  - `/commits` (переворачиваются: старые → новые), `/notes`;
  - `/diffs`; при ошибке не 401/403 или пустом ответе — запасной вариант `/changes?access_raw_diffs=true`;
  - `/repository/files/:path/raw?ref=` (нового и старого);
  - `/repository/commits/:sha/diff` (добавленные строки кода по коммиту, для скорости);
  - `/repository/tree` (корень: CLAUDE.md, .claude, конфиги, `.gitlab/merge_request_templates`; каталоги base — соседние .cs и .csproj).
- Параллельно по 8 запросов.
- Повтор при 429 и 5xx: до 4 попыток, `Retry-After` не больше 30 с. Раньше здесь был бесконечный цикл.
- Таймаут 60 с.
- Если дифф пустой (большой файл), он строится сам через DiffPlex.

**Локальный git:** диапазон merge-base..head, `--name-status -M`, `git show`, numstat по коммитам, базовая линия через `ls-tree`. `HasMrMetadata=false`, если описание не передано: тогда сигнал описания MR пропускается.

## 9. Решения, уроки, подводные камни

- **Решения:**
  - C#/Roslyn вместо Python: точный разбор C#, а пользователь и так .NET-команда;
  - интерпретируемая модель (признаки + логистическая калибровка) вместо нейросети: объяснимость, мало данных, всё локально;
  - базовая линия — код проекта, а не история автора: пользователь запретил опираться на даты.
- **CRLF:** при правке файлов чужих репозиториев сохранять CRLF (`open(..., 'rb')`), иначе весь файл попадает в дифф. `git am --keep-cr` при пересборке.
- **Python-строки в генерации C#:** `\b` превращается в символ backspace. Писать сырые строки или через Write.
- **Heredoc с JavaScript и обратными кавычками** может блокироваться проверкой безопасности Bash. JS-файлы писать через Write.
- **gitlab.com без токена** сильно ограничивает частоту (429) — для тестов использовать поддельный GitLab.
- **Partial clone** (`--filter=blob:limit=150k`): numstat на больших репозиториях медленный (nopCommerce).
- **Контейнер временный:** .NET ставить заново (`dotnet-install.sh --channel 10.0 --install-dir /root/.dotnet`), клоны репозиториев и JSON корпуса пропадают — восстанавливать скриптом.
- **Наш собственный репозиторий** содержит `CLAUDE.md`. Это нормально: детектор анализирует чужие MR, а не себя.

**Типичные «отпечатки» Claude**, которые стоит проверить в других языках (гипотезы, мерить на корпусе):
- **Python:**
