# Оценка качества: фронтенд-детектор (JavaScript / TypeScript)

## Корпус

| Класс | Источник | MR |
|---|---|---|
| **Человек, до 2021** (`human`) | Настоящие MR из 22 публичных фронтенд-проектов, код до июня 2021 года | 154 |
| **Человек, 2022–2024** (`human-modern`) | MR тех же проектов с июля 2022 по июнь 2024 года — современный код, но до выхода Claude Code (февраль 2025) | 73 |
| **Claude Code, обычный режим** (`ai-default`) | Фичи, написанные агентами Claude Code (Opus и Sonnet) в тех же репозиториях на коммитах конца 2020 года | 14 |
| **Claude Code, маскировка** (`ai-masked`) | «Пиши как в проекте»: стиль соседнего кода, короткие неформальные коммиты, русские комментарии и коммиты в 4 образцах | 8 |
| **Claude Code «в дикой природе»** (`ai-wild`) | Настоящие коммиты Claude Code 2025–2026 годов из 57 разных публичных репозиториев: Angular 18, Vue 18, React 21. Оценивались **без прямых следов** (трейлеров, подписей) | 57 |

Проекты человеческого корпуса:
- **React:** excalidraw, react-admin, mattermost-webapp, jitsi-meet, redash, outline, PostHog, JetBrains ring-ui, VKUI.
- **Angular:** bitwarden web/jslib, dspace-angular, ever-gauzy, alfresco-content-app, SAP spartacus, Tinkoff taiga-ui.
- **Vue:** directus, chatwoot, koel, owncloud web, hoppscotch, nextcloud deck, misskey.

Русскоязычные команды — JetBrains, VK, Tinkoff.

**Зачем два человеческих корпуса.** Дикая выборка — код 2025–2026 годов, а корпус «до 2021» — старый код. Без современного человеческого кода детектор мог бы научиться различать «старое против нового», а не «человек против Claude». Поэтому каждая категория ИИ сравнивается отдельно с людьми до 2021 года и с людьми 2022–2024 годов.

Как воспроизвести:
- `python3 scripts/rebuild_corpus.py --lang frontend` — пересобрать JSON по манифестам `corpus/frontend/manifest-*.tsv` и патчам `ai-src/`;
- `scripts/evaluate.sh frontend` — оценка;
- калибровка: `aidetect calibrate corpus/frontend --lang frontend --lambda 2 --target-fpr 0.03 --temperature 1.0 -o model/weights.frontend.json`.

## Результаты (5-кратная перекрёстная проверка, честная оценка)

Модель: экспертные веса из исследования, затем калибровка. Логистическая регрессия, L2-штраф к экспертным весам (lambda = 2), температура 1.0. Смещение сдвинуто консервативно: не больше 3% людей на обучающей части получают ≥ 50% (поправка делается внутри каждой части перекрёстной проверки). Прямые следы Claude Code в оценке не участвуют.

| Сравнение | ROC AUC | Найдено ИИ при пороге 50% | Ложные «ИИ» на людях при 50% |
|---|---|---|---|
| **Весь корпус** (79 ИИ против 227 людей) | **0.902** | 70% | 6% |
| Claude, обычный режим против всех людей | **0.965** | 79% | 6% |
| то же против людей 2022–2024 | 0.951 | 79% | 8% |
| Настоящие коммиты Claude Code против всех людей | **0.929** | 75% | 6% |
| то же против людей 2022–2024 | 0.910 | 75% | 8% |
| Claude с маскировкой против всех людей | 0.60 | 13% | 6% |

Пороги вердиктов (перекрёстная проверка, весь корпус):

| Порог | Ложные «ИИ» на людях | Найдено ИИ |
|---|---|---|
| ≥ 50% | 6% | 70% |
| ≥ 65% («скорее Claude») | **2%** | 54% |
| ≥ 85% («почти наверняка Claude») | **0%** | 33% |

Люди по перекрёстной проверке:
- **до 2021:** медиана 10%, ≥ 65% — 2 MR из 154;
- **2022–2024:** медиана 13%, ≥ 65% — 3 MR из 73.

На итоговых весах (весь корпус, без отложенной части): AUC 0.934, ложные «ИИ» при пороге 50% — 3%, найдено 72%.
- Claude в обычном режиме: 86% найдено, AUC 0.981.
- Настоящие коммиты Claude Code: 77% найдено, AUC 0.962.
- Самый высокий человеческий MR — 68%.

## Выводы

- **Claude Code в обычном режиме распознаётся надёжно** (AUC 0.96–0.98), в том числе на фоне современного человеческого кода.
- **Настоящие коммиты Claude Code** из 57 чужих проектов детектор узнаёт только по коду и процессу (AUC 0.93), хотя эти проекты он не видел. Разница против людей 2022–2024 годов небольшая (0.91). Значит, детектор различает именно Claude, а не возраст кода.
- **Ложные обвинения редки:** при вердикте «скорее Claude» (≥ 65%) — 2% человеческих MR, при «почти наверняка» (≥ 85%) — ни одного.
- **Маскировка «пиши как в проекте» почти полностью прячет Claude от анализа кода** (AUC 0.60, 8 образцов). Это ожидаемо по исследованию и совпадает с C# (там найдено 43%). Дольше всего держатся процесс (скорость, файлы «с первого раза», нет коммитов-доделок) и отписка в Angular.
- Порог настроен консервативно, как требует исследование: лучше пропустить ИИ, чем ложно обвинить человека.

## Какие признаки реально различают

По разделимости на корпусе и весам после калибровки.

**Сильные:**
- форма MR и процесс: тесты в том же MR и их доля, доля новых файлов, «готовность с первого раза», нет коммитов-доделок, скорость, стиль сообщений коммитов;
- ручные привычки: TODO, закомментированный код, `debugger`, `eslint-disable` — за человека;
- комментарии: аккуратные против небрежных; повествования;
- `console.error('Failed to …:', error)` против `console.log`;
- точные проверки в тестах (`toEqual`, `toHaveBeenCalledWith`) против `toBeTruthy`;
- явные типы результата у экспортируемых функций;
- `type="button"`;
- Angular: отписка от подписок;
- обработка ошибок: `instanceof Error`, `response.ok`.

**Слабые или обратные** (калибровка обнулила или снизила):
- сложность и вложенность функций, «магические» числа;
- `ng.ctorReadonly`, параметры колбэков `x =>`, сокращения: на корпусе ИИ здесь не отличается от людей или пишет даже «по-человечески»;
- «модные» API (`signal()`, `<script setup>`, новые методы массивов): только как сдвиг относительно проекта;
- `any`: направление неустойчиво, согласно исследованию агенты добавляют `any` чаще людей.

## Ограничения

- **ИИ-корпус невелик:** 22 MR агентов и 57 настоящих коммитов. Настоящие коммиты сделаны разными людьми с Claude Code: часть, вероятно, доработана вручную, а у 41 из 57 код на TypeScript.
- **Человеческий код 2022–2024 годов** мог быть написан с Copilot или ChatGPT. По постановке задачи это «человек», но такой код «серее» чистого ручного.
- **Корпоративный код обычно «грязнее» открытого**, поэтому ложных срабатываний на нём, скорее всего, меньше. Главный рычаг точности — калибровка на своих размеченных MR (README, «Настройка под вашу команду»).
- **Маленькие MR** (< 60 строк JS/TS) анализируются плохо; меньше 30 строк — вердикт «недостаточно кода».
