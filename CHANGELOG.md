# История версий

## 1.0.0 — 5 ноября 2026 (ветка `v1`, тег `v1.0.0`)

Первая версия: детектор кода Claude Code в **C#**-мердж-реквестах GitLab. Подробности — README, docs/CONTEXT.md, docs/EVALUATION.md.

- **Анализ MR по ссылке GitLab** (API v4, собственный сервер или gitlab.com). Вероятность в %, вердикт, надёжность, краткое объяснение, главные признаки ИИ и человека с примерами `файл:строка`, оценка по файлам, вклад групп сигналов.
- **~90 признаков в 16 группах:**
  - прямые следы Claude Code;
  - XML-doc, комментарии (включая русские), именование (включая транслит), современный синтаксис, защитный код, async и токены отмены, логирование, исключения, структура и идиомы агента, ручные привычки, форматирование, тесты;
  - форма MR, коммиты и процесс (скорость, «с первого раза», реакция на ревью);
  - отличие от стиля проекта.
- **Поправки** на код проекта (базовая линия) и на его конвенции (StyleCop, XML-doc, `.editorconfig`, commitlint, шаблоны MR).
- **Калибровка** на корпусе из 140 MR (121 человеческий из 19 публичных проектов, 19 Claude): перекрёстная проверка — AUC 0.955, точность 95%, 2% ложных срабатываний на людях. Веса — `model/weights.json`.
- **Режимы:**
  - консоль (`run.sh` / `run.cmd`);
  - веб-страница (токен на вкладку, спиннер, список проверенных MR);
  - `batch`, `fetch`, `--git`, `--load`, `eval`, `calibrate`, HTML/JSON-отчёты;
  - общий доступ: `--host` / `--password` / `--gitlab-host`, `share.sh` (туннель Cloudflare).
- **Запуск** на macOS и Windows без ручной установки .NET.
- 50 модульных тестов; браузерный тест веб-страницы и поддельный GitLab — `tests/web`.
