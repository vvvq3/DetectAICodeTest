# История версий

## 2.0.0 — 6 ноября 2026 (ветка `v2`)

Второй язык — **фронтенд (JavaScript / TypeScript: React, Angular, Vue)** — и архитектура под много языков. Подробности — README, docs/frontend/, docs/CONTEXT.md.

- **Выбор языка** на странице сразу после ссылки на MR: «C# (.NET)», «JavaScript / TypeScript (фронтенд)», «Авто (по файлам MR)». Выбор запоминается. В консоли — `--lang csharp|frontend|auto`.
- **Стек проекта в отчёте:**
  - для фронтенда — `package.json` ближайшего пакета, `angular.json`, импорты, например «TypeScript 4 · Angular 10 · NgRx · RxJS · SCSS · Karma»;
  - для C# — `*.csproj`, например «C# · .NET 8 · ASP.NET Core · EF Core · xUnit».
- **Предупреждение**, если в MR есть код другого языка.
- **Фронтенд-детектор:**
  - собственный лексер и мини-парсер на C#: JS/TS/JSX/TSX, шаблонные строки, regex, блоки Vue, шаблоны Angular, CSS/SCSS/LESS; Node.js не нужен;
  - около 90 признаков в 18 группах, новые группы — типизация TypeScript, идиомы фреймворков, разметка и доступность, стили;
  - конвенции из конфигов: Prettier, правила и пресеты ESLint/TSLint, tsconfig, stylelint, husky;
  - исключение сгенерированного кода и скелетов Angular CLI.
- **Качество фронтенда** (перекрёстная проверка, 306 MR: 227 человеческих, включая 73 современных, 22 MR агентов Claude Code и 57 настоящих коммитов Claude Code):
  - AUC 0.902;
  - ложные «ИИ» на людях 2% при пороге 65% и 0% при 85%;
  - Claude в обычном режиме — AUC 0.965, настоящие коммиты Claude Code — 0.929.
- **Архитектура:**
  - ядро `AiDetect.Core` не зависит от языка;
  - языки — модули `AiDetect.Languages.CSharp` и `AiDetect.Languages.Frontend` с интерфейсом `ILanguageAnalyzer`, регистрация в `AppLanguages.cs`;
  - веса — `model/weights.<язык>.json`, корпус — `corpus/<язык>/`.
- **Детектор C# не изменился:** вывод `eval` на 140 MR корпуса C# побайтно совпадает с версией 1.0.0.
- **Калибровка:** `--target-fpr`, `--temperature`, `--exclude`, метрики перекрёстной проверки по категориям корпуса.
- **Тесты:** 102 модульных теста (50 — ядро и C#, 52 — фронтенд); браузерный тест страницы — 21 проверка.

## 1.0.0 — 5 ноября 2026 (ветка `v1`, тег `v1.0.0`)

Первая версия: детектор кода Claude Code в **C#**-мердж-реквестах GitLab. Подробности — README, docs/CONTEXT.md, docs/EVALUATION.md.

- **Анализ MR по ссылке GitLab** (API v4, собственный сервер или gitlab.com). Вероятность в %, вердикт, надёжность, краткое объяснение, главные признаки ИИ и человека с примерами `файл:строка`, оценка по файлам, вклад групп сигналов.
- **~90 признаков в 16 группах:**
  - прямые следы Claude Code;
  - XML-doc, комментарии (включая русские), именование (включая транслит), современный синтаксис, защитный код, async и токены отмены, логирование, исключения, структура и идиомы агента, ручные привычки, форматирование, тесты;
  - форма MR, коммиты и процесс (скорость, «с первого раза», реакция на ревью);
  - отличие от стиля проекта.
- **Поправки** на код проекта (базовая линия) и на его конвенции (StyleCop, XML-doc, `.editorconfig`, commitlint, шаблоны MR).
- **Калибровка** на корпусе из 140 MR (121 человеческий из 19 публичных проектов, 19 Claude): перекрёстная проверка — AUC 0.955, точность 95%, 2% ложных срабатываний на людях. Веса — `model/weights.json`.
- **Режимы:**
  - консоль (`run.sh` / `run.cmd`);
  - веб-страница (токен на вкладку, спиннер, список проверенных MR);
  - `batch`, `fetch`, `--git`, `--load`, `eval`, `calibrate`, HTML/JSON-отчёты;
  - общий доступ: `--host` / `--password` / `--gitlab-host`, `share.sh` (туннель Cloudflare).
- **Запуск** на macOS и Windows без ручной установки .NET.
- 50 модульных тестов; браузерный тест веб-страницы и поддельный GitLab — `tests/web`.
